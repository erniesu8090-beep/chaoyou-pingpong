# 🏓 朝友桌球俱樂部 - 雙打會內賽積分系統操作手冊

本系統是專為朝友桌球俱樂部雙打會內賽設計的 **10級 Elo 積分與會員管理系統**。採用極簡零配置（Zero-Configuration）架構，支援電腦與手機跨裝置 Wi-Fi 實時同步。

---

## 🌟 系統核心特色

1. **雙打專屬 Elo 核心引擎**：支援「個人期望值權重制（個人戰力對等修正）」與「隊伍平均平分制」雙模式。
2. **區域網路實時同步**：只需執行電腦端伺服器，手機連上同 Wi-Fi 即可實時同步讀寫，資料安全儲存於電腦硬碟。
3. **免伺服器降級模式**：支持直接雙擊 `index.html` 執行，自動切換至純單機 LocalStorage 儲存，具備極佳的相容性。
4. **批次自動錄入與新球員自註冊**：直接貼上比分文字（如：`張三/李四 3:1 王五/趙六`），系統會自動解析並為未註冊球員創建檔案，毋需事先手動新增。
5. **原排/新排對比列印日報表**：自動還原 A4 雙欄對稱版型，支援一鍵列印成 PDF (自動隱藏網頁按鈕) 與 CSV 匯出。
6. **PWA 原生 App 體驗**：支援添加到手機主畫面，提供極速離線快取與全螢幕操作介面。

## 🚀 快速啟動與裝置同步指南

### 電腦主機端 (PC Server)
1. 雙擊執行資料夾底下的 **`啟動伺服器.bat`**。
2. 系統會自動開啟一個輕量的 PowerShell 伺服器視窗（請保持此視窗開啟，不要關閉）。
3. 伺服器會**自動喚醒您的預設瀏覽器**，並載入 `http://localhost:8080/index.html`。
4. *備註：所有資料都會即時寫入資料夾內的 `database.json` 檔案中，安全性高且方便手動備份。*

### 手機 / 平板端 (Mobile Devices)
1. 電腦端啟動伺服器後，命令提示字元視窗上會顯示手機連線網址（例如：`http://192.168.31.161:8080/index.html`）。
2. 確保您的手機與電腦連接在**同一個 Wi-Fi 網路**（需在同一個網段）。
3. 在手機瀏覽器輸入該網址即可開啟系統。
4. **安裝原生 App**：在手機 Chrome 瀏覽器中點擊選單 -> **「新增至主畫面」** 或 **「安裝應用程式」**，即可在手機桌面上生成捷徑，享受無網址列的原生 App 體驗。

## 🔄 區網實時同步與手動整理

在頂部導航 Logo 右側設有**毛玻璃同步狀態燈（同時也是同步按鈕）**：

* 🟢 **`📶 區網同步中 🔄`**：表示目前運作於伺服器同步模式。在任一裝置新增或修改資料後，其他裝置只需**點擊此狀態燈**（或下拉重整網頁），即可實時向伺服器拉取最新資料並自動無感刷新畫面，無需手動整頁重新整理。
* 🟡 **`💾 單機模式`**：表示您直接雙擊 `index.html` 執行（`file://` 協定）。此時資料僅儲存於當前瀏覽器的 LocalStorage 中。
* 🔴 **`⚠️ 同步失敗 (點擊重試) 🔄`**：表示網路斷線或電腦端伺服器被關閉。資料已安全暫存於手機 LocalStorage 中，您可以點擊狀態燈重新連線以補送資料至伺服器。

> [!TIP]
> **初次資料遷移與上傳**：
> 若您先前一直使用單機版（`file://`），現在想改用伺服器版。請在電腦上開啟 `http://localhost:8080`，點選右上角狀態燈 **`📶 區網同步中 🔄`**，系統會偵測到伺服器為空，並**自動將您電腦的舊資料上傳至伺服器 `database.json` 中**。隨後手機即可直接同步取得！

## 🏓 賽事成績登錄說明

系統提供兩種成績登錄方式：

### 1. 單場手動登錄
- 選擇「隊伍 1」與「隊伍 2」的兩位選手（支援名字即時搜尋與互斥防錯）。
- 輸入兩隊大局數比分（如 3 : 1）。
- 下方 **「實時勝負與積分預估」** 會即時計算雙方贏球/輸球後的積分增減與新等級，確認無誤後點選「提交比賽紀錄」即可。

### 2. 批次快速登錄 / 貼上成績（強烈推薦）
- 點選「⚡ 批次快速登錄 / 貼上成績」分頁。
- 直接貼上包含 `/`（隊友分隔）與比分的文字，例如：
  ```text
  張三/李四 3:1 王五/趙六
  張三/王五 2:3 李四/趙六 (11:9, 5:11, 11:7, 8:11, 9:11)
  ```
- **新選手自動註冊**：若貼上的名單包含尚未註冊的新人（例如 "趙六"），系統會在解析時**自動建立新會員**，並給予系統預設分（可於系統設定中修改預設分，例如 1200 分），大幅省去一個個手動新增球員的時間。
- **CSV 檔案載入**：亦支援直接載入包含賽事紀錄的 CSV 檔案。

## 📋 產生存次積分日報表

1. 點選導航列進入 **「歷史賽事」**。
2. 點選右上角的 **`📋 產生單日積分表`** 按鈕。
3. 彈出的報表視窗會自動撈取所有有對戰紀錄的日期，預設載入最新一天（會內賽當天）。
4. **排名對比**：報表表格採雙欄對接排版，按起始積分由高到低排序。表格中會清晰顯示每位選手當天的：
   - **`原排`**（當天比賽前的排名）。
   - **`新排`**（當天比賽後的新排名）。
   - **上升/下降箭頭**：若名次提升會顯示綠色 **`▲`**，若退步則顯示紅色 **`▼`**。
5. **A4 PDF 列印**：點選「🖨️ 列印 / 儲存 PDF」，系統會隱藏網頁按鈕與導航欄，格式完美契合 A4 白底黑字版面，可直接儲存為 PDF 或印出紙張。
6. **匯出 CSV**：點選「匯出 CSV」可導出 Excel 可開的試算表。

## ⚙️ 系統備份與重置

前往 **「系統設定」** 分頁：
* **資料備份 (JSON格式)**：下方的文字框會即時顯示整個資料庫的備份代碼。選取全部複製並另存為 `.json` 檔案即完成備份。
* **資料還原**：將備份的 JSON 文字貼回該框框，點選「匯入 JSON 備份」即可還原。
* **重置資料庫**：點擊「警告：清除所有資料」，可清空所有球員與歷史賽事。
* **載入示範數據**：點擊「載入示範數據」，可一鍵注入系統預設的 10 名虛擬會員及多場歷史對戰，供測試體驗。

## 🛠 常見問題排除

1. **手機打開網頁後，狀態燈顯示「同步失敗」？**
   - 請檢查手機是否連上了與電腦**相同的 Wi-Fi 網路**（有些人家中有 2.4G 與 5G 兩個頻段或訪客網路，必須在同一個 IP 網段內才能相通）。
   - 檢查電腦的 Windows 防火牆是否阻擋了伺服器連接埠（8080）。
2. **手機上點擊手動同步，畫面沒有重新整理？**
   - 請確認電腦端已經用瀏覽器開啟過 `http://localhost:8080` 並成功將舊資料上傳至伺服器。
   - 若手機曾下載過舊版 PWA，請在手機 Chrome 網頁上**下拉重新整理數次**，以強制瀏覽器更新至最新快取版本（v7）。
